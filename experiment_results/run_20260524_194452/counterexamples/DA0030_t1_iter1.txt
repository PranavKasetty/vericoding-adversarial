- Why it fails: The helper declarations in `<vc-helpers>` are syntactically invalid Dafny — a predicate cannot have an explicit `: bool` return type annotation, causing a parse error that prevents the entire file from being verified, violating the postcondition `result == "Yes" || result == "No"` since no result is ever returned.
